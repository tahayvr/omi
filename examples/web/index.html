    Every mode

    Pick one: Omi morphs there from wherever it is.

    One color, any color

    Omi is drawn in its canvas's CSS color, so it takes your page's accent, or anything else.

    Put Omi on your page

    Copy omi.js and omi.json from the kit, then: 

    <canvas id="omi" style="width: 200px; height: 200px; color: #7aa2f7"></canvas>
<script src="omi.js"></script>
<script type="module">
  const kit = await (await fetch("omi.json")).json();
  const omi = new Omi(document.getElementById("omi"), kit);
  omi.set("idle");          // and later: omi.set("thinking"),
  omi.look(1, 0);           // omi.look(0, 0), omi.on("settled", …)
</script>

    The kit's README has every option, and this page's source is the rest of the example.
